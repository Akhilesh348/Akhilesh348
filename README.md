### Featured Projects

#### [Harmful Meme Detection in Indic Languages](https://github.com/Akhilesh348/Multilingual-Memes-Classification-Harmful-Non-Harmful-)

**Multimodal Machine Learning · NLP · Computer Vision**

A multimodal ML system for detecting harmful and non-harmful memes across Indian languages.

* Worked with **8,000+ multilingual memes** across Hindi, Telugu, Tamil and Kannada.
* Developed open-source handcrafted **Telugu and Kannada harmful-meme datasets**.
* Built a multimodal pipeline combining **IndicBERT, CLIP/VGG-19, OCR and ConceptNet**.
* Investigated OCR noise, slang, class imbalance and implicit cultural context.
* Achieved approximately **3–5% Macro-F1 improvement** over text + vision baselines through multimodal integration.
* Built a **FastAPI inference application** for model deployment.

`Python` `PyTorch` `IndicBERT` `CLIP` `OCR` `Computer Vision`

#### [CareerTrack – Placement Management System](https://github.com/Akhilesh348/CareerTrack-Placement-Management-System)

**Backend Engineering · Database Systems · Distributed Systems**

A placement management platform designed around database internals, backend APIs and distributed data management.

* Designed a **21-table relational schema** for students, companies, jobs, applications and interviews.
* Implemented a custom **B+ Tree storage engine** with O(log n) operations.
* Implemented **ACID transactions, Write-Ahead Logging, lock-based concurrency control, deadlock detection and crash recovery**.
* Built a **3-node horizontally sharded MySQL architecture** with hash-based routing.
* Developed **40+ FastAPI REST endpoints** with JWT authentication and 6-tier RBAC.
* Added **audit logging** and extensive unit, integration, concurrency and failure-recovery testing.

`Python` `FastAPI` `MySQL` `B+ Trees` `WAL` `Sharding` `Concurrency`
